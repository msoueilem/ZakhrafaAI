Le mode rapide utilise un générateur procédural (géométrie + palettes, 256×256). Le rendu IA est hybride : la géométrie est dessinée par le même générateur (768×768), puis un modèle d'image Google Gemini la re-rend comme un vrai zellige, tapis ou broderie — en cas d'indisponibilité, l'image procédurale est renvoyée. Le GAN et le modèle de diffusion entraînés décrits dans le rapport restent prévus : ils peuvent être branchés dès que des poids sont fournis.
